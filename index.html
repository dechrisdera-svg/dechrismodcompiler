SECTION 01

What Is Dmc

DechrisModCompiler (DMC) is a script editor and compiler for GTA San Andreas CLEO scripts. You write a script as plain text, press one key, and DMC produces the compiled file that CLEO runs in the game.

Targets

GTA SA Android 2.00      CLEO Android        output .csi / .csa / .cs
GTA SA PC                CLEO 4              output .cs
GTA SA PC                CLEO 5              output .cs / .csi

Main features

  • Editor with syntax highlighting, 3 themes, per-token colors, tabs, session restore, drag and drop.
  • Autocomplete, parameter hints, hover help and opcode search.
  • Live error checking while you type (red squiggles and a Problems list). All errors are shown at once, with "did you mean" suggestions.
  • Compile with F6. Compile + send to phone (ADB) or copy to the PC game with F5.
  • Decompiler: open any compiled .csi / .csa / .cs / .cm as readable source. The result is checked by recompiling it to identical bytes.
  • Hex view of the compiled output.
  • Find / replace, find in files, go to definition, find all references, rename.
  • Code folding, minimap, bracket matching, auto-format, snippets.
  • Variable inspector (hover and Outline panel).
  • Command-line mode.
  • Automatic updates, a News window and a small ad banner (see section 9).
SECTION 02

Install

1. Download DMC_Setup.exe from the website (Download button) or from GitHub Releases. 2. Run it. Windows may show "unknown publisher" because the installer is not code-signed: choose More info, then Run anyway. 3. Start DMC from the Start menu or desktop shortcut.

Where DMC keeps its data

%APPDATA%\DechrisModCompiler

This folder holds settings, the last session, downloaded opcode libraries, cached news and the log file dmc.log. If something goes wrong, dmc.log is the file to send when you report a bug.

PC targets need the GTA SA PC opcode library. DMC offers to download it the first time (Tools > Library manager). The Android library is bundled.

SECTION 03

Quick Start

1. Press New. Choose the target in the toolbar (GTA SA Android 2.00, CLEO 4 or CLEO 5). 2. Type or paste a script, for example:

{$CLEO .csi}
script_name 'HELLO'

wait 1000
while true
    wait 0
    if Player.IsPlaying(0) then
        Char.GiveWeapon(Player.GetChar(0), 24, 100)
        terminate_this_script
    end
end

3. Press F6. The compiled file is written next to the script (or to the output folder set in Tools > Settings). 4. Android: connect the phone with USB debugging on and press F5. DMC copies the .csi into the CLEO folder. PC: press F5 to copy the file to the game's CLEO folder. 5. Start the game. CLEO loads the script.

To read a compiled script: Build > Decompile (Ctrl+Shift+D) or drag the file into DMC.

SECTION 04

Language Guide

DMC uses Sanny Builder 4 style syntax. Old v1 scripts still compile to identical bytes.

Directives

{$CLEO .csi}               output extension (the target default is used if omitted)
{$INCLUDE file.txt}        include another file
{$INCLUDE_ONCE file.txt}   include only once
{$GLOBALS 5000}            base index for named globals ($name)

Script header

script_name 'NAME'
wait 0
0AB1: 1 2 3                raw opcode form

Comments

// line comment
/* block comment */

Variables

0@ 1@ ... 31@              local variables (32@ and 33@ are the timers TIMERA / TIMERB)
$123                       global variable by number
int a, b = 3               named variables
float f = 1.5
Char ped                   class-typed variable (allows ped.IsDead())
int arr[10]                array, use arr[i] = 5
const SIZE = 10            constant
var $g: int                type hint for a global
var 5@: float              type hint for a numbered local

Assignments

a = 5     a += 2     a -= b     a *= 2.0     a /= 2
f =# i                     converts between int and float
c = a + b                  one operator only; use a temp variable for longer expressions

Commands

Class.Member(args)
x y z = Char.GetCoordinates(ped)       outputs go on the left
not Char.IsDead(ped)

Conditions

a > b    a >= b    a < b    a <= b    a == b    a != b
(The operator <> is NOT supported. Use != or test with == and jf.)

Control flow

if cond then ... else ... end
if and / if or      conditions on the following lines, then ... end
while cond ... end
while true ... end
repeat ... until cond
for i = 0 to 9 [step 2] ... end
for i = 9 downto 0 ... end
break
continue

Old style (still works)

if
  cond
jf @LABEL
:LABEL
jump @LABEL
gosub @LABEL
return
terminate_this_script

Raw bytes

hex 4E 00 end

Not supported in this version

  • switch / case, functions with return values, import / export
  • Enums files and model names written as #NAME (use numbers)
  • Mission and external script labels, GTA III / Vice City targets

SECTION 06

Command Line

DMC.exe script.txt [-o out.csi] [--target sa_android|sa_cleo4|sa_cleo5]
DMC.exe --decompile file.csi [-o out.txt]
DMC.exe --disasm file.csi
DMC.exe --update-libs

Exit codes

0   success
1   the script has errors
2   usage, file or library problem
SECTION 07

Settings

Open Tools > Settings.

  • Theme (3 built-in) and per-token colors.
  • Word wrap, minimap, live error checking while typing.
  • Reopen last session on start.
  • Output folder.
  • Download updates automatically (you choose when to install).
SECTION 08

Troubleshooting

ProblemWhat to do
Windows says "unknown publisher"The installer is not code-signed. Choose More info, then Run anyway.
PC target asks for a libraryLet DMC download it (needs internet once), or use Tools > Library manager.
F5 does nothing on AndroidTurn on USB debugging, connect the phone, accept the prompt on the phone, make sure adb is available.
"Cannot understand: ..." errorA line uses unsupported syntax, for example the <> operator. See section 4.
Script compiles but does not work in gameDMC only checks bytes and syntax, it cannot run the game. Check the opcode arguments, then test in game.
Anything unexpectedSend %APPDATA%\DechrisModCompiler\dmc.log with your script on GitHub Issues.
SECTION 09

Updates, News And Ad Banner

Auto-update

  • On start DMC reads latest.json from the GitHub repo.
  • If a newer version exists, DMC downloads the installer in the background.
  • It checks the file size, the SHA-256 hash and a release signature. A file that fails the check is deleted and your install is left untouched.
  • A popup then offers Install now or Remind me later. It comes back every 20 minutes until you install, and a status-bar link stays visible.
  • Install now saves your open tabs, runs the installer silently and restarts DMC.
  • Turn automatic downloads off in Tools > Settings.

News

  • Help > News shows messages from news.json in the repo. The status bar shows how many are unread.
  • The website shows the same news list.

Ad banner

  • A thin strip under the status bar shows messages from app.json. It has a fixed height, never covers or moves any button, and rotates through the items.
  • Clicking an item opens its link.

Privacy

  • DMC only downloads these files. It sends no personal data. The only thing a request carries is the program name and version.
SECTION 10

Maintainer Guide (Repo Owner Only)

Releasing a new version 1. Change the version in dmc/__init__.py and add a section at the top of CHANGELOG.txt. 2. Run build.bat. It runs the tests, builds the installer and creates latest.json automatically. 3. Commit latest.json. Create a GitHub release tagged v<version> and attach installer_output\DMC_Setup.exe. (make_latest.bat recreates latest.json without rebuilding.)

latest.json (generated, do not edit by hand)

{
  "schema": 1,
  "version": "2.1.1",
  "date": "2026-10-14",
  "url": "https://github.com/dechrisdera-svg/dechrismodcompiler/releases/download/v2.1.1/DMC_Setup.exe",
  "size": 12345678,
  "sha256": "<64 hex characters>",
  "sig": "<signature>",
  "notes": ["NEW ...", "FIX ..."]
}

news.json (edit freely, any number of items, newest date first in the app)

{
  "schema": 1,
  "items": [
    {
      "id": "2026-10-14-example",
      "date": "2026-10-14",
      "tag": "update",
      "title": "Headline",
      "body": "Text of the message.",
      "url": "https://example.com"
    }
  ]
}

Each item needs a unique "id" and a "title". "tag", "body" and "url" are optional. Keep the commas and quotes valid or the file is ignored.

app.json (ad banner)

{
  "schema": 1,
  "ads": {
    "enabled": true,
    "rotate_seconds": 25,
    "items": [
      { "id": "ad1", "text": "Banner text", "url": "https://example.com",
        "bg": "#1b3a5c", "fg": "#ffffff" }
    ]
  }
}

Set "enabled" to false to hide the banner for everyone.

Signature

  • Every release is signed with a key made from the shared Dechris password (the password itself is never stored or published).
  • An app built with a different password produces a different key, so its update fails the check and is thrown away.
  • Limit: the key has to be inside the program, so this stops mix-ups and casual tampering, not a determined attacker.
SECTION 11

Status And Limits (Be Honest On The Site)

  • DMC is a beta. The compiler, decompiler, update checker and parsing are covered by automated tests (87 tests).
  • The Windows window, installer and in-game results depend on your system and game and were not all tested on real hardware. Report anything odd.
  • PC CLEO 4 / CLEO 5 output compiles with the same rules as Android but has not been confirmed in a real game.
  • DMC does not include a game debugger or memory tools.
  • Opcode data comes from the Sanny Builder Library.
